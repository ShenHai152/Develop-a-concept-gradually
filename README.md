# 通过不断的迭代逐渐构建知识



功能有点类似于Gemini 的 **学习指导** 功能。目前只能对 **概念** 进行指导，适用于快速了解某概念。通过不断跌点逐渐构建出知识的轮廓。

采用关联式学习模式，很多概念是一起的，少了一个你可能就无法学习这个知识。

比如对数里面的 底数，真数，对数概念。

目前只测试了概念的学习方式，也只适用于概念判别。

大家学习时一定要加上自己所学的专业名称。因为相同的概念在不同的专业中可能代表的意思不一样。
